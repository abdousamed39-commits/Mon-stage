# FITS - Gestion Boutique

Projet de fin de stage - Développement Web - 2025/2026

Application de gestion de stock pour une boutique informatique (FITS) réalisée en HTML, CSS et JavaScript Vanilla.

### Fonctionnalités
- ✅ Affichage du stock (Produit, Prix MRU, Quantité, Référence)
- ✅ Recherche instantanée par nom (insensible aux accents)
- ✅ Ajout de nouveaux produits
- ✅ Modification quantité avec boutons +/- 
- ✅ Alerte visuelle : Rouge = rupture, Orange = stock faible (<=5)
- ✅ Suppression avec confirmation
- ✅ Sauvegarde automatique dans le navigateur (localStorage)

### Démo en ligne
👉 Le site est en ligne via GitHub Pages
